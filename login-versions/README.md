# Login Page Design Versions

## Cara Preview Setiap Versi

Untuk melihat setiap versi, ganti isi file `src/app/login/page.tsx` dengan salah satu file versi di bawah ini:

### V1: Full Gradient Background
**File:** `login-versions/login-v1-full-gradient.tsx`

**Deskripsi:**
- Background gradient sama dengan main app
- Centered card dengan glassmorphism
- Konsisten dengan desain aplikasi
- Form focused dengan branding di atas

### V2: Clean Solid (Professional)
**File:** `login-versions/login-v2-clean-solid.tsx`

**Deskripsi:**
- Clean split screen (inspired by Linear, Vercel)
- Left: Minimal branding dengan solid colors
- Right: Clean white form
- Paling professional dan clean
- Fokus ke form

### V3: Subtle Gradient
**File:** `login-versions/login-v3-subtle-gradient.tsx`

**Deskripsi:**
- Background sangat subtle (slate gradient)
- Card dengan header gradient accent
- Seperti GitHub/Notion style
- Balance antara branded dan clean

### V4: Current Split Screen (Default)
**File:** `src/app/login/page.tsx` (current)

**Deskripsi:**
- Split screen dengan gradient branding di kiri
- Fitur highlights dengan checklist
- Full branding exposure

## Cara Preview

1. Pilih versi yang ingin dicoba
2. Copy isi file versi tersebut
3. Paste ke `src/app/login/page.tsx`
4. Refresh browser di http://localhost:3000/login

## Rekomendasi

- **V2 (Clean Solid)** - Paling professional, cocok untuk SaaS modern
- **V3 (Subtle Gradient)** - Balance yang baik, tidak terlalu plain
- **V1 (Full Gradient)** - Konsisten dengan app, tapi bisa terlalu busy
- **V4 (Split Screen)** - Full branding, tapi kurang fokus ke form

Pilih yang sesuai dengan preferensi Anda!
